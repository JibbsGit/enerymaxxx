# EnergyMaxx Solutions Limited

Marketing website for **EnergyMaxx Solutions Limited** — Renewable Energy, Biodigesters, and Clean Gas Plant solutions.

Built with React, TypeScript, Tailwind CSS v4, and Framer Motion.

## Sections

Hero, About, Services, Why Choose Us, Process, Featured Projects, Testimonials, Contact (with validated consultation form and map embed), Footer, plus a floating WhatsApp button, dark mode, and scroll-to-top.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build     # type-check and build for production
npm run preview   # preview the production build
```

## Project structure

```
src/
  components/   section and UI components
  data/         editable site content (services, stats, projects, testimonials, contact info)
  hooks/        dark mode + count-up animation hooks
```

Update contact details, phone numbers, and social links in [src/data/site.ts](src/data/site.ts).
